# Образец сайта-визитки

Пример страницы, которую можно показать клиенту: карточка частного фотографа и короткий опрос из четырёх вопросов. Интерфейс на русском. Ответы считаются в браузере, заявки никуда не отправляются.

Стек: Next.js, TypeScript, Tailwind, shadcn/ui, Framer Motion.

## Локальный запуск

```bash
npm install
npm run dev
```

Сервер слушает `0.0.0.0:43123`. Откройте [http://127.0.0.1:43123](http://127.0.0.1:43123).

- `/` — карточка
- `/quiz` — опрос

## Скрипты

- `npm run dev` — разработка
- `npm run build` — сборка
- `npm run start` — продакшен на порту 43123
- `npm run lint` — ESLint

Секреты и внешние сервисы не нужны.
