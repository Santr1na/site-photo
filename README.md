# NORDA

Клиентский пример премиального бюро личного позиционирования. Сайт на русском: кинематографичная главная и диагностика «Профиль эксперта» — семь вопросов, четыре архетипа, результат на клиенте.

Стек: Next.js, TypeScript, Tailwind, shadcn/ui, Framer Motion, Lenis.

## Локальный запуск

```bash
npm install
npm run dev
```

Сервер слушает `0.0.0.0:43123`. Откройте [http://127.0.0.1:43123](http://127.0.0.1:43123).

- `/` — главная
- `/quiz` — диагностика

## Скрипты

- `npm run dev` — разработка
- `npm run build` — сборка
- `npm run start` — продакшен на порту 43123
- `npm run lint` — ESLint

Секреты и внешние сервисы не нужны.
